## Кейс 1: Автоматизация проверки лизинговых платежей

**Проблема (AS-IS):**
Проверка ежемесячных актов от лизингодателей и бухгалтерии велась вручную. Директор открывал каждый договор, сверял сумму с графиком платежей и процентной ставкой. Процесс занимал до 3 рабочих дней, был подвержен человеческому фактору и не позволял оперативно выявлять ошибки.

**Моя роль:**
Бизнес-аналитик / Системный аналитик (внутренний заказчик — директор).

**Что сделал:**
- Собрал и проанализировал требования (интервью с директором и бухгалтерией).
- Спроектировал структуру сводной таблицы, объединившей данные из 5+ источников.
- Автоматизировал расчёт расхождений (сумма, НДС, МВЗ, рентабельность).
- Настроил динамические срезы по месяцам, МВЗ и лизинговым компаниям.
- Обучил директора работе с инструментом.

**Результат (TO-BE):**
- Время проверки: **с 3 дней до 2 часов** (в 12 раз быстрее).
- Выявлены системные ошибки в актах бухгалтерии.
- Единая база по **120+ договоров** лизинга.

**Инструменты:** MS Excel (сложные формулы, VLOOKUP, SUMIF, сводные таблицы), BPMN (описание процесса).

**Артефакт:** [`leasing_payments_anonymized.xlsx`](./leasing_payments_anonymized.xlsx) — данные обезличены и изменены случайным коэффициентом для соблюдения конфиденциальности.
