# Кейс №3. Система учёта наёмной техники и анализ затрат по проектам

**Компания:** ГеоЛад-СТП
**Период:** Март 2018 — Ноябрь 2023
**Роль:** Бизнес-аналитик

## Проблема (AS-IS)
Транспортная компания привлекала наёмную технику для проектов в нескольких регионах. Учёт вёлся в разрозненных таблицах, отсутствовала единая база и аналитика. Не было понимания, сколько компания тратит на наёмную технику по МВЗ, подрядчикам и категориям.

## Что сделал
1. **Создал справочник типов ТС (50+ категорий):** автокраны, автобусы, АГП, АЦ, бортовые, вакуумники, ППУ, тралы, тягачи, ЦА-320, ямобуры, топливозаправщики, тракторы, компрессоры и др. Автоматическая подстановка категории через VLOOKUP.
2. **Разработал накопительную базу учёта:** месяц, дата, МВЗ, год, тип ТС, принадлежность, госномер, подрядчик, цена за 1 ч, цена за 1 км, подписанные часы, пробег, стоимость часов, стоимость пробега, стоимость всего, № УПД. Автоматический расчёт стоимости.
3. **Построил сводные таблицы:** по подрядчикам, по МВЗ, по категориям техники — с разбивкой по месяцам и годам (2018–2019).
4. **Провёл анализ аномалий:** выявил случаи задвоения часов, удержания часов в следующем месяце, работы без путевых листов, простои и ремонты.

## Результат (TO-BE)
- **Единая база:** все данные по наёмной технике — в одном месте.
- **Прозрачность:** сводки по МВЗ, подрядчикам, категориям, месяцам.
- **Выявлены аномалии:** задвоение часов, работы без путевых листов, простои.
- **Аналитика:** динамика затрат за 2 года (2018–2019).

## Достижение
По результатам анализа обосновал руководству покупку собственных автокранов, ЦА и площадок вместо наёмной техники.
