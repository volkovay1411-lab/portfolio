# Кейс №2. Экономическая оценка тендеров и проектов

## Контекст
Транспортная компания участвовала в тендерах крупных заказчиков нефтегазового сектора. Требовалось оценить экономику проектов до подачи коммерческого предложения.

## Что делал
- Изучал требования заказчика: техзадание, интервью, согласование условий.
- Собирал и структурировал входные параметры проекта.
- Формировал модель экономики: себестоимость, тариф, рентабельность по каждому типу ТС.
- Проводил план-факт анализ исполнения, выявлял отклонения, готовил корректирующие мероприятия.

## Результат
- По одному из проектов доказал руководству экономическую невыгодность — проект закрыт по моей рекомендации.
- Выявлял проблемные ТС и статьи затрат, готовил мероприятия по снижению расходов.

## Про NDA
Все проекты конфиденциальны. Реальные формы, цифры и данные заказчиков не публикую. Подход и логику готов разобрать на собеседовании.
